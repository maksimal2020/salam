# Имитация экранов (не настоящее приложение)

`index.html` — утверждённый макет «яркий дружелюбный» с названием Salam! и знаком «S!»: показывает экраны так, как их описывает Flutter-код (цвета и формы разделов, тексты, порядок виджетов, данные настоящего сервера). Это HTML, а не Flutter: настоящие отступы, шрифты, тени и анимации будут отличаться. Нужен, чтобы оценить внешний вид до первой сборки.

`shoot.cjs` — скрипт скриншотов через Playwright для прежней версии макета; под новую разметку его селекторы и сценарии не перепроверялись.
