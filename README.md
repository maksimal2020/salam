# Salam! — документы для мигрантов

Приложение для иностранных граждан в России: документы, адреса, советы и объявления на русском, таджикском, узбекском, киргизском и казахском.

**Основной клиент — мобильное приложение на Flutter (Android и iOS) в папке [`mobile/`](mobile/README.md).** Папки `server/`, `content/` и `docker-compose.yml` — общий сервер и данные для него. Веб-версия (PWA, папки `web/` и `e2e/`) сделана раньше, продолжает работать и пока служит проверочным клиентом сервера; если она не нужна, эти две папки можно удалить вместе со строками про `web` в `package.json` и `Dockerfile`.

Четыре раздела: **Документы** (каталог и персональный список «Мой список»), **Где оформить**, **Полезные советы**, **Объявления**. Языки: русский, таджикский, узбекский (латиница), киргизский, казахский.

Стек: Flutter/Dart (мобильное приложение), Node + Express + TypeScript (API), PostgreSQL, Docker Compose. Веб-версия: React + TypeScript + Vite.

## Допущения

- **Пилотный город — Москва.** Город в задании не был указан, поэтому записи об учреждениях заведены только для Москвы. Остальные города (43 в справочнике) работают без учреждений: приложение честно сообщает, что проверенных адресов нет.
- **Официальные источники во время разработки были недоступны**, поэтому весь каталог, учреждения и советы — **демонстрационные записи** (`"status": "demo"`). В интерфейсе они помечены штампом «Демо, не проверено». Сроки и стоимость у них не заполнены.
- Группы гражданств (ЕАЭС / безвизовые не из ЕАЭС / другое) — справочное допущение, его нужно подтвердить.
- Город, гражданство и язык выбираются независимо. Всё личное (язык, город, ответы для списка, отметки) хранится на устройстве (в мобильном приложении — в памяти телефона). Регистрация нужна только для объявлений.

## Запуск

### Через Docker Compose

```bash
docker compose up --build
# приложение: http://localhost:3000
```

При первом старте применяются миграции, импортируется контент и создаётся модератор из `SEED_MODERATOR_EMAIL` / `SEED_MODERATOR_PASSWORD` (по умолчанию `moderator@example.local` / `change-me-please` — **сменить вне локальной разработки**).

Переменные (можно положить в `.env` рядом с `docker-compose.yml`):

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `INCLUDE_DEMO_CONTENT` | показывать демонстрационные записи | `true` (перед запуском — `false`) |
| `SEED_MODERATOR_EMAIL`, `SEED_MODERATOR_PASSWORD` | первый модератор | см. выше |
| `POSTGRES_PASSWORD` | пароль базы | `app` |

### Без Docker (разработка)

Нужны Node 22 и PostgreSQL 16.

```bash
npm install
export DATABASE_URL=postgres://app:app@127.0.0.1:5432/migrant   # база должна существовать
npm run db:migrate
npm run content:import
npm run dev:server        # API на :3000
npm run dev:web           # интерфейс на :5173, проксирует /api
```

Продакшен-сборка: `npm run build && npm start` (сервер сам отдаёт `web/dist`).

Прочие команды: `npm run create-moderator -w server -- <email> <пароль>`, `npm run content:check`, `npm run coverage`.

## Структура

```
content/            всё, что обновляется отдельно от кода
  i18n/*.json         тексты интерфейса, по файлу на язык (ключи одинаковые)
  reference.json      гражданства, цели, этапы, флаги, «где проверить»
  situations.json     жизненные ситуации
  cities.json         города (регион, координаты центра, псевдонимы, районы)
  catalog/documents.json   каталог: правила применимости, переводы, источники
  institutions.json   учреждения: услуги, территория обслуживания, адреса
  tips.json           редакционные советы
  moderation.json     правила автоматической проверки объявлений
server/             API, миграции, импорт, скрипты, API-тесты
mobile/             мобильное приложение Flutter (Android и iOS), см. mobile/README.md
web/                веб-версия (PWA): интерфейс, service worker, манифест
e2e/                проверки веб-версии в браузере (+ вымышленные тестовые данные)
docs/COVERAGE.md    таблица покрытия (создаётся `npm run coverage`)
```

Роли: `user` и `moderator`. Просмотр, справочники и «Мой список» доступны без входа. Публикация, отклик и жалоба — после входа.

## Как обновлять материалы

Правьте файлы в `content/`, затем:

```bash
npm run content:check     # структура, переводы, ключи интерфейса, смешение алфавитов
npm run content:import    # загрузка в базу (с Docker: docker compose exec app node server/dist/scripts/import-content.js)
```

Либо без командной строки: войдите модератором и отправьте `POST /api/mod/reload-content`. Каталог смонтирован в контейнер, пересобирать образ не нужно.

Правила, которые проверяет импорт:

- запись со статусом `verified` обязана иметь `checked_at` и хотя бы одну ссылку-источник; у учреждения — ещё и адрес (или сайт для онлайн-услуги);
- `deadline` и `cost` разрешены только у `verified`-записей;
- все пять языков должны иметь одинаковые наборы ключей, одинаковые подстановки (`{city}`, `{date}`…), без слов со смешанной латиницей и кириллицей.

**Добавить город:** добавьте объект в `cities.json` (id, name, region, lat, lon, aliases; при необходимости `districts`) и импортируйте. Код менять не нужно.

**Добавить учреждение:** запись в `institutions.json`. Поле `serves` задаёт территорию: `{"city": "khimki", "districts": null}`, район-ограниченная `{"city": "moscow", "districts": ["cao"]}` или `{"scope": "country"}`. Если учреждение в одном городе обслуживает другой, в карточке автоматически показывается его фактический адрес и пояснение.

**Опубликовать запись:** поменяйте `status` на `verified`, укажите `checked_at` и ссылки на официальные страницы. Потом проверьте `docs/COVERAGE.md`.

## Объявления и модерация

- Категории: работа, жильё, куплю и продам, услуги, отдам бесплатно. Срок размещения 7, 14 или 30 дней; по истечении объявление скрывается.
- **Вакансии** сначала проходят модератора. **Остальные** публикуются сразу и попадают в очередь «Недавно опубликованные».
- Автоматически отклоняются: продажа документов, фиктивная регистрация, работа с предоплатой от соискателя, номера паспортов, телефоны, почта и ссылки на мессенджеры в тексте. Связь только через форму отклика, автор видит только то, что отвечающий написал сам. Адрес почты автора нигде не публикуется. Правила — в `content/moderation.json`. Для таджикского, узбекского, киргизского и казахского правила короче русских, их нужно расширить с носителями.
- Три разные жалобы автоматически скрывают объявление до решения модератора.
- Модератор: одобрить, отклонить (с причиной), скрыть (с причиной), вернуть.

## Город и геолокация

- После выбора языка предлагаются «Определить мой город» и «Выбрать вручную» (или «Выбрать позже»).
- Координаты отправляются на сервер один раз (`POST /api/cities/locate`, не в адресе), там сопоставляются с ближайшим городом из справочника и **не сохраняются и не логируются**. Браузер запоминает только `id`, название и регион.
- Дальше 700 км от любого города списка приложение предполагает, что пользователь ещё за пределами России, и предлагает ручной выбор. Это эвристика: для далёких регионов добавьте города в `cities.json`.

## Проверки

```bash
npm test          # 26 API-тестов (нужна база; по умолчанию postgres://app:app@127.0.0.1:5433)
npm run build     # сначала собрать интерфейс
npm run e2e       # 23 сценария в Chromium (Playwright)
```

Для `npm run e2e` нужен Playwright с установленным Chromium (`npm i -D playwright && npx playwright install chromium`); в окружении разработки он был предустановлен.

Переменные: `TEST_ADMIN_URL` (подключение к серверу БД для создания тестовых баз), `E2E_SHOTS` (куда класть скриншоты). Тесты используют вымышленные записи из `e2e/fixtures/content/`, они не попадают в продакшен-контент.

## Что подтвердить перед запуском

1. **Весь каталог документов** (15 записей): сведения, источники, дата проверки, сроки и стоимость.
2. **Все учреждения Москвы** (9 записей): адреса, часы, телефоны, сайты, запись, территория обслуживания, перечень услуг. Для налоговых инспекций добавьте привязку к районам.
3. **Группы гражданств** и правила применимости документов (`rules` в каталоге).
4. **Переводы** на таджикский, узбекский, киргизский и казахский — только машинная проверка структуры, нужна вычитка носителями. Подробные шаги документов переведены только на русский (приложение показывает пометку).
5. **Советы редакции** (10 записей) — редактор должен одобрить и сменить статус.
6. **Правила модерации** для не-русских языков.
7. Выключить `INCLUDE_DEMO_CONTENT`, сменить пароль модератора и пароль базы, настроить HTTPS и резервное копирование.
8. Второй этап (не реализован): справочник частных компаний, помогающих с документами.
